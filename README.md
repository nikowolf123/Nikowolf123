## `whoami`

I'm a 22-year-old from Tyrol, Austria, with a fairly serious inability to leave interesting problems alone.

One day I'm trying to squeeze more performance out of a game engine. The next I'm studying emergency medicine. I like knowing **why** something works, not just memorizing the steps to make it work.

I'm not going to pretend I know everything. Quite the opposite: I know just enough to realize how much there is to learn, and that makes me want to learn even more.

## What I'm working on

### 🎮 Console internals & open-source experimentation

I enjoy learning how game consoles, compatibility layers and emulators work — particularly the gap between *"could this theoretically work?"* and *"here's what would actually need to be implemented."*

I've been exploring the **AnyPS5** project and contributing to discussions/code, including [PR #4053](https://github.com/boykopovar/AnyPS5/pull/4053). I’m interested in systems programming, graphics, platform architecture, debugging and the wonderfully complicated problem of making software run somewhere it was never designed to run.

### 🗄️ Digital preservation

Games, Flash-era weirdness, old media, obscure software: I hate the idea that pieces of internet history can just vanish.

I'm hosting a large personal archive with mass HDD storage, SSDs for active games, reliable backups and as little vendor lock-in as possible.

**If I own something, I want to be able to keep it.**
